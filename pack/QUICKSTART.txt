WinTune — Quick start (portable ZIP)
====================================

IMPORTANT — pick the ZIP that matches your PC:
----------------------------------------------
  WinTune-*-win-x64.zip     most Intel/AMD PCs (AMD64)
  WinTune-*-win-arm64.zip   Windows on ARM only

  Check ARCH.txt in this folder. Running the wrong architecture shows:
  "This app can't run on your PC".

Optional — add this folder to PATH (new terminals only):
  Add-To-Path.cmd

Launchers check ARCH.txt against this PC before starting wintune.exe.

From Git Bash in this folder you can also run:

  ./wintune.exe doctor
  ./wintune.exe help

WinTune is a command-line tool. Use one of these to get started:

RECOMMENDED first run:
----------------------
  Run-Doctor.cmd         One-shot health check (doctor) — start here
  Launch-WinTune.cmd     Interactive CLI (Enter runs doctor on first prompt)
  Start-Tray.cmd         System tray icon (native Win32)
  wintune.exe            Built-in interactive menu (Enter = doctor)

Interactive mode
----------------
After launching, type any command at the  wintune>  prompt, for example:

  doctor
  scan
  tui
  tui --theme compact
  top --watch
  startup --include-tasks
  apply WT-POWER-001 --yes
  help

Shortcuts: press 1-9 for common commands (see the on-screen menu).

Or open PowerShell / CMD in this folder:

  wintune doctor
  wintune scan
  wintune help
