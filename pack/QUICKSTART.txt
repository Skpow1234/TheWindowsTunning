WinTune — Quick start (portable ZIP)
====================================

WinTune is a command-line tool. Use one of these to get started:

RECOMMENDED — double-click one of these:
----------------------------------------
  Launch-WinTune.cmd     Full interactive CLI (PowerShell prompt)
  Launch-WinTune.ps1     Same (if PowerShell is your default)
  Run-Doctor.cmd         One-shot health check (doctor)
  wintune.exe            Interactive menu (built-in, no PowerShell needed)

Interactive mode
----------------
After launching, type any command at the  wintune>  prompt, for example:

  doctor
  scan
  top --watch
  startup --include-tasks
  apply WT-POWER-001 --yes
  help

Shortcuts: press 1-9 for common commands (see the on-screen menu).

Or open PowerShell / CMD in this folder:

  wintune doctor
  wintune scan
  wintune help
